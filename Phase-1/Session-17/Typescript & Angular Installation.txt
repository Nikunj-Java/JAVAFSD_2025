3. Binding in Angular
-----------------------------------------------------------------

Types:
	1. Source to View (.ts file to .html file)
	2. View to Source (.html file to .ts file)
	3. Source to View and View to Source (Two Way Binding)

Types of Data Binding:
	1. Interpolation
	2. Property Binding
	3. Class | style Binding
	4. event Binding
